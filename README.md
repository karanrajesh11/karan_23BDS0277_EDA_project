# EDA Course Project – Phase 1 & Phase 2 | Karan Rajesh (23BDS0277)

This repository contains the Phase 1 and Phase 2 submissions for the Exploratory Data Analysis (EDA) course project. The project uses the allocated **US Seat Belts dataset** to perform data loading, statistical analysis, missing value handling, data cleaning, data transformation, and exploratory data analysis using univariate, bivariate, and multivariate techniques.

**Phase 1** focuses on understanding and preparing the dataset through descriptive statistics, missing value analysis and handling, data cleaning, transformations, and exploratory visualizations using Pandas, NumPy, Matplotlib, and Seaborn. Various statistical measures and visualizations are used to identify patterns, relationships, distributions, and trends within the dataset.

**Phase 2** extends the analysis with additional 1D, 2D, and multidimensional exploratory analysis. It includes frequency distributions, frequency polygons, violin plots, ECDF and KDE plots, Q-Q plots, chronological analysis, categorical and quantitative variable analysis, contingency tables, row and column profiles, chi-square analysis, Cramér's V, 3D visualizations, PCA, parallel coordinates, and multivariate analysis. The phase also applies clustering techniques including **K-Means clustering, hierarchical clustering with different linkage methods, divisive clustering, spectral clustering, and MST-based analysis**, along with cluster evaluation and outlier analysis.

The project has been implemented in **Python** using Pandas, NumPy, Matplotlib, Seaborn, SciPy, and Scikit-learn, following the concepts covered during the EDA theory classes. The analyses in both phases aim to provide a comprehensive understanding of the dataset and demonstrate the application of statistical, visualization, dimensionality-reduction, and clustering techniques.
